# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub Issues, Pull Requests, or Discussions.

Report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/manny-py/sakhtanie/security/advisories/new).

Where available, include:

- a clear description of the vulnerability;
- the affected component or path;
- reproduction steps or a proof of concept where it is safe to provide one;
- the potential impact; and
- a suggested mitigation, if available.

Do not include secrets, tokens, personal information, or unnecessary production data. Avoid public disclosure until the maintainer has had a reasonable opportunity to investigate and remediate the vulnerability.

General bugs that do not contain sensitive security details may use the public [Bug Report form](.github/ISSUE_TEMPLATE/bug_report.yml).

Conduct violations are not security reports. Send them privately to `contact@sakhtanie.ir` and follow the [Code of Conduct](CODE_OF_CONDUCT.md). This address is not the preferred channel for security vulnerabilities; use GitHub Private Vulnerability Reporting instead.
