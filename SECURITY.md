# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public GitHub issue.

This repository does not currently publish a private vulnerability-reporting channel. The maintainers should update this policy if a verified private channel becomes available.

Do not put tokens, secrets, analytics credentials, personal information, or operational exploit details in public issues, pull requests, discussions, logs, screenshots, or other public content.

General bug reports that do not contain sensitive security details may use the repository's bug report form.
